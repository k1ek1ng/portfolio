# Internship write-ups

Projects I built as the sole Software Engineering Intern at Cypress Industries,
summer 2026. The code is proprietary, so these describe the work and the
decisions behind it, shared with permission. Customer and supplier names are
omitted.

- [**Customer PO to sales order**](case-study-po-to-so.md): PO PDFs become ERP
  sales orders after a person approves them. Saves about an hour per order.
- [**AP invoice matching and vouchering**](case-study-ap-invoice-agent.md):
  supplier invoices are checked against the PO and receipts, then posted to the
  ERP after approval.
- [**AR invoice delivery**](case-study-ar-invoicing-pipeline.md): the day's
  invoices become one reviewed email draft per customer.
